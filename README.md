## ✨ Overview

**Random Information Portfolio** is a visually engaging single-page web application designed to present knowledge across:

- Technology  
- Science  
- Psychology  
- History  
- Space  
- Business  
- Environment  
- Future Innovations  

It focuses on **cross-domain thinking** — connecting ideas from different fields to improve creativity and understanding.

---

## 🚀 Features

- 📖 Dynamic content rendering using JavaScript  
- 🎨 Clean and modern UI (Tailwind CSS)  
- 📊 Structured sections with key insights & stats  
- 📌 Interactive Table of Contents  
- ⬆️ Smooth scrolling + progress indicator  
- ⚙️ Customizable theme (Element SDK)
